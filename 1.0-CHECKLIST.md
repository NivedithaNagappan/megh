# Megh 1.0 Readiness Checklist

Refreshed 2026-11-13. Every open item has a GitHub issue in the [`1.0.0` milestone](https://github.com/meghjs/megh/milestone/1); the issue holds the details, this file is the overview. Finished items are listed under [Done](#done) at the end. Paths are relative to the repo root unless noted.

Where things stand: security, CLI, packaging, docs and the API cleanup are done. What's left is core correctness, six production features, tests, and trimming the public API before it becomes a promise.

**0.6.0** is ready to release from `main`: the API cleanup (#94), the new docs (#95), `run()` reading `PORT` (#102) and the safer scaffolded `.env` (#103). The upgrade guide is `docs/content/getting-started/upgrading-0.6.md`. #108 (trimming exports) is the next breaking change; aim it at 0.7.0.

`@meghjs/data` (TypeORM and Knex) is frozen and kept as it is. It may be dropped in favour of Megh ORM (`packages/core/src/orm`), so its open bugs are listed separately and are not 1.0 blockers.

## P1: Core correctness

Paths are under `packages/core/src/`.

**HTTP and app**

- [ ] #51 **`PartialType` / `OmitType` / `PickType` don't carry class-validator rules,** so derived DTOs validate nothing and `PartialType` doesn't make fields optional. (`http/map-types.ts`)
- [ ] #52 **Missing decorator metadata gives unclear failures.** Fail at boot with a message that names the compiler setting. (`http/params.ts`)
- [ ] #53 **Controller registration:** `useControllers([...])` replaces earlier lists; `getApp(options)` ignores options after the first call.
- [ ] #54 **OpenAPI output:** nested DTO `$ref` components, `new classType()` during schema generation, Scalar's `spec.content`.
- [ ] #55 **One optional-peer loader** instead of the copy-pasted `require*` helpers.
- [ ] #104 **Auto-discovery guesses `src` → `dist`,** ignores tsconfig and tsx, and only warns on failure.
- [ ] #106 **The default error logger logs query strings,** so tokens can end up in logs.

**Config and storage**

- [ ] #97 **`GetConfig` reports any error in `config()` as "not registered".** (`config/config.ts`)
- [ ] #98 **`MEGH_DOTENV=false` doesn't stop `Environment` reading `.env`;** an unparsable `.env` empties every value. (`config/environment-variables.ts`)
- [ ] #99 **Export `EnvironmentVariableNotFound`.** Good first issue.
- [ ] #105 **`FileStorage` checks symlinks only when reading,** not when saving. (`storage/file-storage.ts`)

**Queue, scheduler and events**

- [ ] #56 **Events:** listeners keyed by class name, `once` listeners firing twice or dropped, failed queued events lost. (`events/event-registry.ts`)
- [ ] #57 **`DispatchOptions.transports` accepts `"kafka" | "rabbitmq"`** and silently ignores them. (`events/socket-dispatcher.ts`)
- [ ] #100 **Scheduler:** tasks not stopped when startup fails, `close()` doesn't wait for running jobs, `useScheduler({ path })` typing, same-name classes deduplicated, option types not exported.

## CLI

- [ ] #101 **`megh doctor` accepts Node 20,** but the packages require Node 22. Good first issue.
- [ ] #107 **`megh migrate` needs the TypeScript sources** at deploy time; add a mode that runs compiled migrations.

## Public API surface

A 1.0 surface is a promise; the [versioning policy](docs/content/reference/versioning.md) excludes "Other exports" only until 1.0.

- [ ] #108 **Trim accidental exports and fix naming:** about 100 internal exports (metadata keys, registries, helpers, router types), the `ValidateOptons` typo, duplicate aliases, untyped `GlobalOptions`.
- [ ] #71 **Lint debt:** about 885 ESLint warnings, mostly `no-explicit-any`. Type the public types first (`IRequest`, `GlobalOptions`, `use*` options, `IMeghApplication`).

## Candidates for 1.x

- Interceptors, pipes and request-scoped DI
- A feature/module system: optional per-feature controllers, middleware, config, models and services for larger teams (design discussed 2026-11-13; `mapFeatures()` was removed in #94 to free the name)
- OpenTelemetry tracing and Prometheus metrics
- A storage driver interface with S3, GCS and Azure, signed URLs and range requests
- Cache: LRU and size limits, `remember` / getOrSet, `@Cacheable`, key namespacing
- Queue: DLQ, default retry and backoff, bull-board
- Distributed locks for the scheduler, so every replica doesn't run every cron
- Socket.IO Redis adapter, rooms and presence API
- Real Kafka and RabbitMQ event transports
- `@Transactional` on top of `DB.transaction()`
- Mail and notifications
- CSRF, cookies and sessions, JWT helpers in core (the CLI already scaffolds JWT auth)
- i18n
- CLI: `make:event`, `make:listener`, `make:job`, `make:task`, `make:guard`, `make:test`, `openapi:export`, `upgrade`

## `@meghjs/data` (frozen)

Known bugs, left as they are while the package is frozen. Recheck before fixing if it is kept.

- Query operators (`Like`, `In`, `Not`, ...) are re-exported as types only, so they are undefined at runtime.
- `MeghRepository.transaction()` runs outside the transaction for `@Repository` classes.
- Pagination differs between the TypeORM and Knex providers and Megh ORM.
- `@Repository` breaks constructor injection in subclasses.
- No tests for repository transactions.

## Done

Finished since the first audit, kept short for the record.

**Security (P0):** `@Authorized` fails closed; handlers get the validated DTO with whitelisting; storage path traversal, confinement and upload overwrite fixed; `Content-Disposition` injection; credentials no longer logged; 5xx details hidden in production; per-call `FileStorage` transforms.

**Core:**
- Pluggable error handling: exception filters, `@Catch`, `@UseFilters`, `useErrorHandler`, framework 4xx statuses kept, 404s in the Megh shape (#40).
- #43: one pipeline order (middleware → authentication → `@Authorized` → validation → handler); inline routes get `mapPatch`, bound middleware, authentication, `.authorized()` and result handling.
- #44: `useHealth()` with `/health` and `/ready` (Megh ORM registers a `database` check); request IDs on responses and log lines, `getRequestId()`.
- From #41: `useScheduler({ path })`; `@UploadFile` awaits the save; `run(port, { host })` defaults to `0.0.0.0`; shutdown timeout, exit codes and cache close; socket listener errors logged; `@All`; metadata cache keyed on the class; `.env` parsed once; `@HttpCode`, `Results.*` and `HttpResponse.*` statuses; `src` → `dist` resolution.
- Built-in `Validator` accepts `0` and checks `min` / `max` / `exact` / `optional`.
- Producer-only queues (`@Queue({ worker: false })`) and an in-memory / sync queue driver for tests; workers never start on import; `@Queue` keeps constructor injection.
- Scheduler decorators use own metadata; node-cron v4.
- In-memory cache honours TTL; JSON logs in production.
- Collection `min()` and `paginate` fixed.
- Lifecycle hooks: `onInit`, `onReady`, `onClose`, `close()`.
- typedi replaced with Megh's own container; `mock-db` no longer exported.
- OpenAPI security schemes linked to `@Authorized`.
- Megh ORM with migrations, seeders and factories.
- `ControllerOptions` trimmed to `path` and `name`; legacy auth types and dead helpers removed.

**CLI:** commander-based parsing with help and version flags; per-command options; `new --minimal` and refusing to overwrite; `-f` honoured everywhere; generated code compiles; one casing helper and kebab-case file names; pinned versions in new projects; non-zero exit codes; separate bin and library entries; project-root detection and Windows paths; `build` and `serve` reworked; templates in stubs; `start`, `route:list`, `doctor`, `make:dto`, `make:resource`, migrations and seeding commands; CLI tests on temp directories.

**Packaging and release:** monorepo with lerna fixed versioning and conventional commits; tag-gated release workflow with build, typecheck, lint and test; vitest and ESLint flat config; husky 9 and npm-based lint-staged; `exports` maps and `sideEffects`; CommonJS-only documented; MIT licence files; optional peers declared; class-validator and class-transformer as peers; unused dependencies removed; CI on every PR with core coverage thresholds.

**Docs:** VitePress site with Fundamentals and Integrations sections; typos fixed; pages for authentication and authorization, caching, file uploads and static files, dependency injection, logging, error handling, Megh ORM, and upgrade guides; contributor instructions in `docs/README.md`.

**Docs (#95, closes #72–#83):** expanded introduction; AI placeholder removed; pages for application options, configuration, scheduler, testing, deployment, security hardening, versioning policy, API reference and FAQ; `useMultipart` limits and `useStaticFiles` `root` fixed in the READMEs; `MeghScheduler` exported.

**0.6.0 breaking changes:** `run()` defaults to `PORT` (#102); new projects keep `NODE_ENV` out of `.env` (#103).

**API cleanup (#94, closes #86–#93), breaking, ships in 0.6.0:** removed `useHttps`, `useSerialization`, `mapFeatures`, `MeghSocketIo`, `DuplicateRouteException`, `mapRoute`, `registerMiddleware` and the schema aliases; framework logs go through `internalLogger`; `noUnusedLocals` on in core; avleon assets pruned.
